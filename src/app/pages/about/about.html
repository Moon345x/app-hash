Sobre nosotros

Más que una simple demo.

Esta aplicación fue pensada para mostrar cómo organizar contenido y navegación de manera elegante, con una estructura clara y una experiencia visual cuidada.

El enfoque está en mantener un equilibrio entre funcionalidad y estética, para que cada pantalla se sienta profesional, accesible y fácil de extender.

Objetivo

Presentar una app con varias vistas y un layout limpio para practicar routing.

Estilo

Se utilizan tonos suaves, cards elevadas y un sistema visual consistente.
